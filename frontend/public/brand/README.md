# TraceLens brand assets

Original identity for TraceLens — **Explainable Anomaly Intelligence** (ProgVision, AEGYTHON 2026).

## The mark

A six-blade aperture lens holding a telemetry signal trace. Three connected evidence nodes sit on the trace; the highest peak is blue, marking the detected anomaly. It is built from geometry only — no stock art, no generic target or AI-brain shapes.

Colours: deep navy `#0B1F3A`, teal `#0E7C7B`, soft teal `#E8F4F3`, secondary blue `#2563EB`, muted `#64748B`.

## Files

| File | Use |
|---|---|
| `logo-horizontal.svg` | Landing page, reports, light backgrounds |
| `logo-horizontal-inverse.svg` | Navy sidebar and dark-navy surfaces only |
| `logo-compact.svg` | App avatar, tables, small light surfaces |
| `logo-compact-inverse.svg` | Compact mark on navy surfaces |
| `logo-hero.svg` | Full hero lockup with descriptor and tagline |
| `../favicon.svg` | Browser tab icon |

## Usage rules

- Light theme only. There is no dark-mode logo.
- Minimum size: compact mark 28 px, horizontal logo 160 px wide.
- Keep clear space of at least half the mark height around it.
- Do not recolour, stretch, rotate, add shadows or place on gradients.
- Use the inverse files only on `#0B1F3A` navy.
- The React component `src/components/Logo.tsx` mirrors this mark for in-app use; keep the two in sync.
